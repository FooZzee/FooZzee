### `// ABOUT`

Стример и разработчик. Создаю высококонтрастные телеметрические HUD-оверлеи, интерактивные чат-боты и нативные Windows-утилиты для **OBS Studio**. Каждый инструмент проектируется под реальные прямые эфиры и обкатывается в боевых условиях на собственных трансляциях по **Euro Truck Simulator 2**, **American Truck Simulator** и автосимуляторам.

> **Streamer & Developer.** Building high-contrast real-time telemetry HUD overlays, interactive chat bots, and native Windows utilities for **OBS Studio** — engineered and battle-tested live on my own **ETS2**, **ATS**, and sim-racing broadcasts.
